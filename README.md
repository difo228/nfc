# Petroretail NFC — страница гостя

Гость касается телефоном NFC-таблички, ставит оценку смайлом и при желании указывает причину, оставляет комментарий и телефон.

Сайт: https://difo228.github.io/nfc/

| Табличка | Ссылка для метки |
|---|---|
| 🧾 Касса | https://difo228.github.io/nfc/#b522-kassa |
| ⛽ Заправщик | https://difo228.github.io/nfc/#b522-fuel |
| 🚪 Выход | https://difo228.github.io/nfc/#b522-exit |
| 🚻 Туалет | https://difo228.github.io/nfc/#b522-wc |

Для другой АЗС замените `b522` на её номер без дефиса (например, `z001`).

Отели Keruen Inn (коды KI-01…KI-03, как в дашборде): зоны `reception` (ресепшн), `room` (номер), `rest` (ресторан), `lobbywc` (туалет в лобби) — например https://difo228.github.io/nfc/#ki01-room. С QR-кода к ссылке добавляется `-qr`: `#ki01-room-qr`.

Логотипы сетей — `img/brands/` (прозрачные PNG; у Keruen Inn отдельный вариант для тёмной темы). Все ссылки и QR-коды есть на странице `#tags`, результаты — на `#results`.

## Сохранение отзывов в Google Таблицу

1. Создайте новую Google Таблицу.
2. Откройте **Расширения → Apps Script**, удалите пример кода и вставьте весь файл [`apps-script.gs`](apps-script.gs). Сохраните.
3. Нажмите **Развернуть → Новое развертывание** → тип **Веб-приложение**. Запуск от имени: **Я**, доступ: **Все**. Нажмите **Развернуть** и разрешите доступ к таблице.
4. Скопируйте ссылку веб-приложения (заканчивается на `/exec`) и вставьте её в `index.html`:
   ```js
   endpoint:'https://script.google.com/macros/s/…/exec',
   sheetUrl:'https://docs.google.com/spreadsheets/d/…',   // необязательно: кнопка «Открыть таблицу»
   ```

Как это работает:
- Строка добавляется сразу после касания смайла, так что оценка не теряется, даже если гость сразу ушёл. Причины, комментарий и телефон дописываются в ту же строку.
- Оценки 1–2 получают статус «Новая». После разбора поставьте в таблице «В работе» или «Решено», и страница `#results` это покажет.
- Страница `#results` получает из таблицы последние 500 отзывов, **без телефонов**. Телефоны видны только в самой таблице, поэтому давайте доступ к ней только тем, кто перезванивает гостям.
- Если поменяли код в Apps Script: **Развернуть → Управление развертываниями → ✏️ → Версия: новая**. Тогда ссылка `/exec` останется прежней.
